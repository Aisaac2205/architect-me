## Installation

### Prerequisites

- Node.js (v18 or higher)
- npm, pnpm, or yarn

### Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/Aisaac2205/Portafolio_Isaac.git
   cd Portafolio_Isaac
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   pnpm install
   ```

3. **Configure environment variables**
   ```bash
   cp env.example .env
   ```
   
   Edit the `.env` file and configure the necessary variables (EmailJS, etc.)

4. **Start development server**
   ```bash
   npm run dev
   ```

5. **Open in browser**
   
   Navigate to `http://localhost:5173`

## Usage

### Local Development

To start the development environment:

```bash
npm run dev
```

The site will open at `http://localhost:5173` with hot-reload enabled.

### Production Build

To create an optimized build:

```bash
npm run build
```

Compiled files will be generated in the `dist/` folder.

### Production Preview

To preview the production build locally:

```bash
npm run preview
```
